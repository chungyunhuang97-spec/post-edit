# Photo Poster Cutout

Upload a photo and drag geometric "cutout" windows over it — the same crop
shows up live inline in a poetic caption above. Includes a canvas size
picker, 16 selectable cutout shapes (including a Y2K set: heart, flower,
blob, sparkle, moon, lightning), per-cutout colors, photo pan/zoom, and PNG
export rendered by hand on a `<canvas>` for reliability on iOS Safari.

## Development

```bash
npm install
npm run dev
```
